Cycle

Terms & anchors

Each term has its own anchor (a known date = known cycle day) and a last day of classes. Weekdays after a term’s last day and before the next term’s anchor are term break — no cycle day, nothing to log. Every term except the current one needs an end date. The usual way to start a new term is tapping the Today card on its first day.

Class schedule per cycle day

One class per line, as “time | subject” (e.g. “7:30–8:00 | CLE”). Lines without a “|” are shown without a time. Switching days keeps your edits.

School days

Subjects & their cycle days

Day numbers separated by commas, e.g. “4,7”. The first subject gets the orange highlight.

Family sync (share with another phone)

Both phones enter the same database URL and family code; every change then appears on the other phone within seconds. Needs a free Firebase Realtime Database — one-time setup, steps provided with this version.

Sync copies the log to your Firebase database, so it leaves this phone. Anyone holding both the URL and the code could read it — keep the code private (it’s long and random on purpose). If two edits collide, the most recent one wins.

Backup

Data lives only in this browser (localStorage). Backups from any older version import fine — they’re upgraded automatically. Export a copy now and then in case the browser clears it.
